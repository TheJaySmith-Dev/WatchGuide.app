# WatchGuide

WatchGuide is a modern, beautiful, and intelligent companion for tracking movies and TV shows. Discover trending content, manage your watchlists, and get personalized recommendations powered by AI.

## 🌟 Key Features

*   **Universal Discovery**: Browse trending movies and TV shows from all major streaming services in one unified interface.
*   **GuideAI Assistant**: Your personal movie expert. Ask for recommendations, find similar titles, or get detailed info about any media.
*   **Custom Hubs & Lists**: Create personalized content hubs (e.g., "Marvel Universe", "Cozy Weekend") or import lists directly from Trakt.
*   **Smart Sync**: Seamlessly sync your watchlist, history, and ratings across devices using Simkl and Trakt integrations.
*   **Beautiful UI**: A polished, responsive interface with a focus on visuals, including a new desktop dock and glassmorphic design elements.
*   **Global Availability**: Check streaming availability for your specific region (US, UK, CA, etc.).

## 🛠️ Tech Stack

*   **Frontend**: React, TypeScript, Vite
*   **Styling**: Tailwind CSS, Lucide React (Icons)
*   **State/Storage**: LocalStorage, Custom Hooks
*   **APIs**: TMDB (Media Data), Simkl & Trakt (Sync), Poe (AI)

## 🏃‍♂️ Run Locally

**Prerequisites:** Node.js (v18+)

1.  Clone the repository:
    ```bash
    git clone https://github.com/TheJaySmith-Dev/WatchGuide.app.git
    cd WatchGuide.app
    ```

2.  Install dependencies:
    ```bash
    npm install
    ```

3.  Set up environment variables:
    Create a `.env` file and add your API keys (if applicable for your fork).

4.  Run the development server:
    ```bash
    npm run dev
    ```
