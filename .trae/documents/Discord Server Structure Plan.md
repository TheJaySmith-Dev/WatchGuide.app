Here is a comprehensive setup for the **WatchGuide** Discord server, designed to foster community, support development, and showcase user lists.

### 👑 Roles & Permissions

**1. Administrator / Owner**
*   **Color:** Gold (`#FFD700`)
*   **Permissions:** `Administrator` (All permissions)

**2. Moderator**
*   **Color:** Blue (`#3498DB`)
*   **Permissions:**
    *   `Manage Messages` (Delete spam/spoilers)
    *   `Kick Members` / `Ban Members` / `Timeout Members`
    *   `Manage Nicknames`
    *   `Mention @everyone, @here` (Use sparingly)
    *   `View Audit Log`

**3. Developer**
*   **Color:** Green (`#2ECC71`)
*   **Permissions:**
    *   `Manage Channels` (In Dev category)
    *   `Priority Speaker`
    *   `Send Messages` in `#changelog`

**4. Beta Tester** (Early access users)
*   **Color:** Purple (`#9B59B6`)
*   **Permissions:**
    *   Access to `🚧 BETA LABS` category
    *   `Attach Files` (For screenshots/recordings of bugs)
    *   `Add Reactions`

**5. Cinephile** (Active/Level-up Role)
*   **Color:** Pink (`#E91E63`)
*   **Permissions:**
    *   `Use External Emojis`
    *   `Change Nickname`
    *   `Embed Links`

**6. Member** (Default)
*   **Color:** Light Grey (`#BCC0C0`)
*   **Permissions:**
    *   `View Channels`
    *   `Send Messages`
    *   `Read Message History`
    *   `Connect` / `Speak` (Voice)
    *   ❌ Deny: `Mention @everyone`, `Attach Files` (optional anti-spam)

---

### 📂 Categories & Channels

#### 🏠 **ENTRANCE**
*   **#📢│announcements**
    *   *Perms:* Read-only for everyone. Admin/Dev can post.
    *   *Purpose:* Major updates (like the "Cinematic Home" update), downtime alerts.
*   **#📜│rules**
    *   *Perms:* Read-only.
    *   *Purpose:* Server rules and guidelines.
*   **#👋│welcome**
    *   *Perms:* Read-only system messages.
    *   *Purpose:* "Welcome @User to WatchGuide!"
*   **#🎭│roles**
    *   *Perms:* Read-only.
    *   *Purpose:* Reaction roles bot (e.g., "Notifications", "Movie Watcher", "Anime Fan").

#### 🚀 **WATCHGUIDE HQ**
*   **#🆕│changelog**
    *   *Perms:* Read-only.
    *   *Purpose:* Granular update logs (e.g., "Fixed mobile logo size", "Added Hub vs Row option").
*   **#🗺️│roadmap**
    *   *Perms:* Read-only.
    *   *Purpose:* Future plans (e.g., "Coming Q3: Trakt Scrobbling").
*   **#💡│feature-requests**
    *   *Perms:* Slow mode enabled (2 mins).
    *   *Purpose:* Users suggest ideas. Use a bot for upvoting.
*   **#🐛│bug-reports**
    *   *Perms:* Members can post.
    *   *Purpose:* "Thumbnails not loading", "Login failed". (Encourage using a template).

#### 💬 **THE LOUNGE**
*   **#💬│general**
    *   *Purpose:* Chill chat about anything.
*   **#🎬│movie-talk**
    *   *Purpose:* Discussing films.
*   **#📺│tv-talk**
    *   *Purpose:* Discussing series.
*   **#📂│share-your-lists**
    *   *Purpose:* **Crucial for your app.** Users paste their `watchguide.app/#/list/...` links here.
*   **#⚠️│spoilers**
    *   *Purpose:* Unrestricted spoiler talk.

#### 🆘 **SUPPORT**
*   **#❓│help-desk**
    *   *Purpose:* Community-led help ("How do I connect Simkl?").
*   **#🎫│tickets**
    *   *Purpose:* Ticket tool for private account issues.

#### 🚧 **BETA LABS** (Private Category)
*   *Access:* Beta Testers & Devs only.
*   **#🧪│beta-chat**
*   **#💥│beta-bugs**

#### 🔊 **VOICE CHANNELS**
*   **🔈 Lounge**
*   **🍿 Watch Party** (Screen share enabled)
*   **🎮 Gaming**
